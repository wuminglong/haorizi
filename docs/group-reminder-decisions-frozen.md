# HaoRiZi 产品边界

以下约束已实施，后续变更需要同步代码、API 契约和测试：

- 当前阶段群组码用于进入工作台并共同编辑提醒
- 管理员通过独立 `admin.html` 维护全部群组、提醒和发送记录
- 提醒规则只包含提醒时间、提前天数和是否当天提醒
- H5 普通首页使用“提醒 / 日程 / 我的”三个标签；默认展示提醒列表
- 点击提醒条目进入编辑，右下角绿色加号新增提醒
- 第一版只使用 PushPlus 群组推送
- 一个业务群组绑定一个 `push_topic_code`
- 重置群组码后，旧 group session 立即失效
- 旧个人版数据不迁移，也不保留兼容接口
- 农历年支持 1901–2099；无闰月默认跳过，无三十默认按月末，创建时允许修改策略
- 微信 OpenID 和成员归属下一阶段实施；上线时切换为“看全部、只改自己”
