# 隐私说明

HaoRiZi 用于记录群组共享的生日、节日和纪念日，并通过 PushPlus 群组发送提醒。

## 保存的数据

- 群组：名称、群组码、说明、PushPlus topic code
- 提醒：名称、日期、日历类型、农历策略、规则、备注和相关人
- 发送计划与日志：计划时间、发送状态、错误码和脱敏后的请求/响应

当前阶段不使用第三方账号登录，也不收集第三方账号标识。PushPlus token 和 secret 只保存在服务器环境变量中，不会下发给前端。后续接入微信 OpenID 前必须更新本说明并按最小化原则取得授权。

知道群组码的人可以查看和修改该群组提醒。群组码泄露时，管理员应立即重置群组码，使旧 session 失效。

生产环境必须使用 HTTPS、限制数据库公网访问，并定期备份数据库。
